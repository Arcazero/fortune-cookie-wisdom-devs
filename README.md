One original line of fortune-cookie wisdom for a software developer, written for make.fun's "Fortune Cookie Wisdom for Developers" bounty.

The fortune:

> The deploy you dread will go out clean, and the silence after it is the applause you earned.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
